## 自由度与关节（出处：A §四肢机械结构 行327/429-439）

**合计 28 DOF = 双臂 14（单臂 7）+ 头部 2 + 腰部 4 + 底盘 8。**

单臂 7 关节运动范围（度）：

| 序 | 关节 | 范围 | 备注 |
|---|---|---|---|
| 1 | 肩关节俯仰 | +168°~-168° | 向前摆为正 |
| 2 | 肩关节侧展 | +30°~-180° | 向身体内侧为正（**非对称**） |
| 3 | 肩关节周转 | +170°~-170° | |
| 4 | 肘关节俯仰 | +130°~-105° | 手肘向上为正（**非对称**） |
| 5 | 腕关节周转 | +170°~-170° | |
| 6 | 腕关节侧展开 | +43.75°~-43.75° | |
| 7 | 腕关节俯仰 | +90°~-90° | |

> 腰部（A 行436-437）：旋转 +213°~-123°、俯仰 +150°~-150°。
> ⚠️ 表为**机械边界**，非推荐安全姿态；`0 位` 在范围内但=手臂伸直，不是安全位姿（见 cloud_adapter 注释）。

## SDK / 控制约定（出处：A §SDK 行820-837）

| 项 | 约定 |
|---|---|
| SDK | `pypilot`（`PilotSDK` + `arm*` 系列） |
| `armMoveJoints/armGetJoints` 单位 | **度（°）** |
| robotId | **1=左臂、2=右臂、3=腰部** |
| 末端执行器 | 标配二指夹爪，CAN/CAN FD/485（A 行348/363），离散开/合 |
| 训练 20 维状态/动作 | 左臂 7 + 右臂 7 + 腰 4 + 左右夹爪各 1 |
| 真机图像 | **目前不支持 RGB 数据推流**（pypilot 相机回调只有点云、无 RGB）；桥 observation 不含图像，只上传关节 + 夹爪 |

## 电气/网络接口（出处：B §电气接口 / 网络）

| 接口 | 说明 |
|---|---|
| 调试网口 | **RJ45 以太网 1000Mbps**，CAT5e+ 网线；机器人通常经局域网与上位机/调度通信 |
| 其他 | USB、CAN/CAN FD/485；核心控制器 = 底盘控制器 + 上集成控制器 |
| 无线 | 双频段 WiFi（冗余覆盖） |

## 与桥/R2C 的映射约定（详见本子包 README + robot_xifeng_config.yaml）

| R2C 侧 | 桥内部 | 隙锋 pypilot |
|---|---|---|
| `joint_states`：`left_arm_1..7`,`right_arm_1..7`（**弧度**） | `arm_positions`（弧度） | `armMoveJoints`（**度**，桥换算 rad→deg） |
| `end_effector_states`：`left_gripper`,`right_gripper`（**0-100** 开合） | `gripper_positions` | 串口 hex 离散开/合（阈值 50） |
| （无图像）| — | 目前不支持 RGB 推流，observation 不含 `images.*` |

> 单位换算（度↔弧度）与夹爪开合阈值统一由 `cloudrobo_r2c.robots.xifeng.robot_real` 处理；
> 云端 / cloud_adapter 用弧度，产品侧给度时需先 `radians(度)`。
